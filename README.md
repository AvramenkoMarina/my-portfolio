# Portfolio project 
This project is a personal portfolio website built with Next.js, showcasing sections like About Me, My Work, and Contact. It includes a mobile-friendly responsive design and smooth animations for better user experience.

## Demo
https://my-portfolio-ten-ecru-43.vercel.app/

## Tech Stack
- Next.js
- Tailwind CSS
- React Hooks

## Setup Instructions
- git clone https://github.com/your-username/your-repo-name.git
- cd your-repo-name
- npm install
- npm run dev
- Open http://localhost:3000 in your browser.
